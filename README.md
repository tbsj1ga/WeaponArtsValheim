# WeaponArts

Мод для Valheim: **активные способности по оружию** — одна клавиша, эффект зависит
от того, что в руках. Развитие ShieldTaunt: таунт башенного щита станет частным
случаем (порт в следующей фазе). Сделан так, чтобы работать и с игроком **без
мода** (как таунт).

Полное ТЗ и статус по фазам — в `..\ShieldTaunt\TASK-weapon-arts.md`.
История версий — `CHANGELOG.md`.

## Как это устроено

Активка выбирается по `skillType` оружия и хвату (1H/2H). При активации игрок
«печёт» в свой ZDO id активки, срок (по серверному времени) и уже
скейл­нутую силу. Урон/эффекты применяет **владелец задетого существа**: патч
`Character.RPC_Damage` читает активку атакующего из его ZDO и правит удар
(множитель урона, яд-DoT, стаггер, вампиризм). Один путь для любого модового
атакующего, где бы ни был владелец моба.

- Эффекты **только по существам** (PvP-safe); боссам — `BossEffectFactor`, боссы
  иммунны к стаггеру.
- Скейл силы и длительности от тира оружия и навыка владения (потолок окна +50%).
- Кулдаун свой у каждой активки + глобальный GCD.

Прокси для ваниль-игрока (эмоция/challenge или слово в чате, провайдер рядом) —
реализован. Синк с хостом, окно настроек, кистень (Вихрь), эффекты/скилл-ап
таунта — следующие фазы.

## Настройки

`BepInEx\config\j1ga.weaponarts.cfg`: клавиша, HUD, глобальный GCD,
`BossEffectFactor`, скейлы, и по каждой активке — величина/окно/КД/стоимость.
Консоль (F5): `weaponarts status | list`.

## Установка / сборка

`build/WeaponArts.dll` → в
`%AppData%\r2modmanPlus-local\Valheim\profiles\Valheim\BepInEx\plugins\WeaponArts\`
или `build.ps1 -Install`. Сборка `csc.exe` (C# 5), проверка `check-refs.ps1`
(типы, члены, рефлексия, цели Harmony). Клиентский; на сервере — по мере
добавления синка (следующие фазы).
